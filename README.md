# TUDW Frameworks - Interoperabilidad LAR Developers

Este repositorio incluye una base mínima para resolver la conexión **Frontend (React + Tailwind)** con **CMS (Strapi)** para CapiLAR.

## Estructura

- `frontend/`: aplicación React con adaptación visual CapiLAR y consumo de `GET /api/services`.
- `cms/`: guía de creación de Strapi y datos de prueba.
- `docs/capturas/`: checklist de capturas solicitadas para evidencia de antes/después.
